# Project Beacon - Mobile Wallet Plan

Project Beacon is the mobile wallet built on top of the Project Alpha payment platform. Project Beacon owner: Ben Okafor.

The Project Beacon beta release is planned for January 20, 2027 with customer Globex Logistics as design partner.

Stack: React Native, TypeScript, GraphQL gateway, PostgreSQL.
